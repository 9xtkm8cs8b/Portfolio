# Mini Pong

A small browser-based Pong-style game built with plain HTML, CSS, and JavaScript.

## Run locally

Because browsers restrict some local file features, run a simple local server:

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000>.

## Controls

- Left paddle: `W` / `S`
- Right paddle: `↑` / `↓`
- Restart match: `Space`
